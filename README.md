# Claude Self-Improving Skills Agents

This project aims to build a "Claude code architect" using multi-agent systems equipped with skills and hooks that can self-improve over time.

## Research: Are people working on this?

Yes! The landscape of self-improving agent architectures has seen significant development. The core concept relies on shifting from simple "prompt-tuning" to sophisticated closed-loop systems where agents learn from their own execution traces, refine their behaviors, and permanently store "learnings."

### Key Concepts in the Field

1. **Skills (Modular Knowledge)**
   Rather than a static, massive prompt, a **Skill** is a structured, modular instruction set (e.g., a `SKILL.md` file) or tool. Agents invoke them on-demand and can self-evolve these skills by mining past failures. If an agent repeatedly fails a task, it generates or refines a skill to handle that edge case.

2. **Hooks (Deterministic Control)**
   Since LLMs are probabilistic, **hooks** (bash scripts, API callbacks, event triggers) are used to enforce deterministic workflows. For example, a hook might mandate that every code snippet generated by a builder agent is passed through a static analyzer before proceeding, guaranteeing reliability.

3. **The Self-Improving Loop (Generate → Reflect → Refine)**
   Most frameworks follow this cycle:
   - **Generate:** Agent performs the task using current skills.
   - **Reflect:** The agent (or a critic agent) analyzes logs/traces for failure patterns.
   - **Refine:** The agent updates its persistent skills (e.g., editing `SKILL.md` or `Learnings.md`) based on the reflection.

### Existing Frameworks & Implementations

- **Claude Code Architect:** Tools like Claude Code are frequently used to build multi-agent teams. In a common pattern, an **Architect Agent** takes requirements and creates a plan, a Builder writes the code, and a Reviewer validates it. "Self-improvement" is achieved via hooks (like `/recursive-improve`) that evaluate performance and commit instruction updates.
- **EvoSkill & Skill-MAS:** These frameworks treat "skills" as evolvable objects. EvoSkill uses iterative failure analysis to optimize agent programs, while Skill-MAS allows a frozen LLM to improve architectural knowledge by evolving a "Meta-Skill" orchestration layer.
- **SiriuS & MARTI:** These utilize Reinforcement Learning for multi-agent systems, using bootstrapped reasoning or tree-search augmented RL to learn from successful collaborative trajectories.
- **EvoAgentX:** An open-source framework optimizing agentic ecosystems through self-evolving algorithms and automated evaluation.

In summary, building a self-improving architect agent with Claude—utilizing structured skills and deterministic hooks—is a highly relevant and cutting-edge pursuit in the current AI engineering landscape.
